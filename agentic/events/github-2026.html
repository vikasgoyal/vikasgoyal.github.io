GitHub Universe 202615 Sessions for Teams Building with Agentic AI

A practitioner's shortlist from the Universe catalog, organized around the seven practice areas of agentic software engineering, from delegating work to agents through evaluating, securing, and operating them.

15 sessions
01

Delegation & agentic workflows

Moving from prompting an assistant to assigning work to agents, and redesigning the delivery pipeline around them.

Stop prompting, start delegating: Configure Copilot to own the work

Ken Muse, Mickey Gousset · GitHub Hands-on · see catalog for time

A hands-on session that layers Copilot's full set of capabilities onto a TypeScript app. You leave with a working project and a clear sense of which capability fits which kind of task.

From writing code to managing agents: Scaling 50+ services at GitHub

Anjuan Simmons · GitHub See catalog for time

GitHub's Lifecycle team built an agentic pipeline in which agents triage issues, research the codebase, draft an implementation plan, and open a draft pull request. The talk covers real numbers, how it was built on Actions and Copilot, and where engineers still choose to write code by hand.

02

Context engineering, memory & skills

What an agent knows, what it remembers, and how that knowledge is packaged and shared across a team.

Treat your AI context as infrastructure

Christopher Harrison · GitHub Thu 1:00 PM PT

Compares custom agents, skills, instruction files, MCP servers, extensions, and plugins: what each one is best at, and how to roll out context consistently as a team's setup grows.

How GitHub taught Copilot to remember and when to forget

Cooper Nederhood, Alejandro Carderera · GitHub See catalog for time

GitHub researchers built a benchmark from sequences of real pull requests and found that accumulated context can actually degrade performance. They'll show how that finding shapes Copilot's agent memory work, including features still in development.

Build once, run on any agent: A practical guide to agent skills

Shishir Tewari · Procore, with Andrea Griffiths · GitHub See catalog for time

A working session on when a recurring workflow deserves to become a reusable skill, drawing on skills built for a production data engineering team.

03

Harness, hooks & extensibility

The scaffolding around the model: the loop, tools, lifecycle events, and the machinery that keeps an agent stable across models.

Inside GitHub Copilot's coding harness: Optimizing across every model

Julia Kasper · Microsoft See catalog for time

How the Copilot team keeps one coding agent performing across OpenAI, Anthropic, and Google models: reproducible benchmarks, thousands of autonomous coding tasks, and LLM-graded assertions that catch regressions early.

I made my Octolamp think with GitHub Copilot CLI hooks

Beatris Mendez Gandica · Nuevo Foundation See catalog for time

A playful demo that wires Copilot CLI lifecycle hooks to a desk lamp, showing how the hooks system works under the hood and how to write your own.

04

Evaluation & verification

Knowing whether agent output is actually correct, and whether a model change made things better or worse.

Your benchmark is lying: What evals actually look like

Walker Chabbott · GitHub, Julia Kasper · Microsoft Sandbox session · see catalog

How Copilot evaluates models in production: what the team measures, and which metrics it stopped tracking because they didn't predict what developers actually experienced.

Beyond pass or fail: How agents verify AI-generated code

Jeff An · Momentic Thu 9:00 AM PT

Agents that investigate a running application, reproduce unexpected behavior, and separate real product bugs from flaky tests or infrastructure failures, all within deterministic limits on what they may touch.

05

Security, guardrails & governance

Enforcing what agents can do through infrastructure, not instruction files, and hardening the pipelines they run in.

Open pull requests, don't merge them: Fine-grained authorization for hosted MCP servers

Nick Taylor · Pomerium Thu 10:30 AM PT

A live demo of an identity-aware proxy that adds per-identity authorization in front of any hosted MCP server, with no upstream changes. In the demo, Copilot can open the pull request, and only a human can merge it.

Disrupting supply chain attacks: A threat framework for GitHub Actions

Steve Glass, Greg Ose · GitHub Wed 2:30 PM PT

Maps known supply chain attack techniques to specific GitHub Actions controls across three layers: the Actions ecosystem, the workflow attack surface, and runner infrastructure.

06

Agents in production operations

Agentic patterns beyond code generation: SRE, incident response, and investigation.

The 2 a.m. RCA agent: Architecting AI that investigates, not hallucinates

Achin Gupta · Intuit, Divya Mahajan · Amazon Thu 9:30 AM PT

A root-cause-analysis architecture in which deterministic code handles signal collection, topology traversal, correlation, and scoring. The language model only explains evidence that was gathered for it.

07

Adoption, org change & the road ahead

Turning tool access into real fluency, adapting team workflows to agent output, and where the models are heading next.

Building AI fluency at UPS

Jared Hatfield · UPS Wed 11:30 AM PT

How UPS moves developers from trying Copilot to using agents to plan, build, and ship real work, and why motivation and measurement matter as much as tooling at enterprise scale.

The view from the labs: What's next for AI-assisted development

Cara Phillips · Anthropic, Rohan Varma · OpenAI, Kate Catlin · GitHub Thu 9:00 AM PT

An interactive panel with leaders from the frontier labs on where AI-assisted development is heading over the next two years.

Stop waiting on your own pull requests: GitHub stacked pull requests in practice

Sameen Karim · GitHub Demo · see catalog for time

A live demo of building a stack of small, dependent pull requests with the GitHub CLI, reviewing it on github.com, and merging each pull request as it becomes ready.
